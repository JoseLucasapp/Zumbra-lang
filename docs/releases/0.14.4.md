# Zumbra 0.14.4 native release/performance stabilization

Zumbra 0.14.4 promotes the Z23 native runtime fixes into an explicit compiler release:

- keeps the runtime memory lifecycle builtins used by long-running native applications;
- keeps the statement-if checker fix needed by desktop pipelines;
- enables stronger release C flags for native builds;
- adds opt-in host tuning through `ZUMBRA_NATIVE_TUNE=native`;
- adds opt-in LTO through `ZUMBRA_NATIVE_LTO=thin`, `1` or `full`.

## Versioning

The CLI version is now `0.14.4`:

```bash
./build/zumbra --version
```

Expected:

```text
0.14.4
```
