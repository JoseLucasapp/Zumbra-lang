# Zumbra 0.14.1

Patch de correção da linha Z18 identificado durante a validação da fundação Z19 do emulador NES/Famicom.

## Corrigido

- o operador `!` agora usa o valor de qualquer `bool`, em vez de depender da identidade interna do objeto;
- comparações de inteiros de largura fixa, como `(flags band 0x02u8) != 0u8`, podem ser negadas corretamente;
- booleanos retornados por operações numéricas, built-ins, funções e campos de `struct` são canonicalizados pela VM;
- igualdade e desigualdade entre booleanos na VM usam o valor lógico;
- evaluator e VM permanecem equivalentes para expressões booleanas derivadas de `u8`, `u16`, `u32`, `u64`, `i8`, `i16`, `i32` e `i64`.

## Regressão reproduzida

```zumbra
struct Header { battery: bool; }
var flags << 0u8;
var parsed << Header((flags band 0x02u8) != 0u8);
show(!parsed.battery); // true
```

Na 0.14.0, a comparação produzia um objeto booleano com valor `false`, mas o operador `!` verificava a identidade interna do objeto e retornava `false`. Na 0.14.1, o operador usa `Boolean.Value`.

## Validação

```

```
