# Zumbra 0.14.2

Zumbra 0.14.2 is a corrective release discovered while closing the Z19 NES/Famicom foundation. It adds native C11 support for the `panic` builtin, which already existed in the evaluator and VM but was rejected by `nativec`.

## Fixed

- `nativec` now recognizes `panic` as a supported builtin.
- The native runtime enforces the one-argument contract.
- Panic values are converted through the same value-to-string rules used by `toString`.
- A triggered panic writes a diagnostic containing `panic: <message>` to `stderr`.
- The process exits with a non-zero status.
- Panics raised inside native tasks continue through the existing task error trap instead of silently terminating the worker.
- Programs that contain panic paths which are not executed now build and run normally.
- Imported assertion helpers, including the Z19 test/runtime guards, can be compiled by the C11 backend.

## Validation

Run the focused regression gate:

```bash
scripts/test-0.14.2-native-panic.sh
```

Then run the complete language regression:

```bash
go test ./...
go vet -unsafeptr=false ./...
scripts/test-z18-tooling.sh
scripts/check-repository-hygiene.sh
```

Validate the release host and version:

```bash
EXPECTED_VERSION=0.14.2 scripts/test-release-platform.sh
```

After installing the CLI, validate the Z19 foundation with:

```bash
EXPECTED_ZUMBRA_VERSION=0.14.2 scripts/test-z19-foundation.sh
```
