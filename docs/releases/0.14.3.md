# Zumbra 0.14.3

Zumbra 0.14.3 moves the real-time desktop/media bridge required by game and emulator projects into the official runtime. Applications can present RGBA framebuffers, queue PCM audio, read keyboard/gamepad state, control VSync, inspect process arguments and obtain Unix time without shipping project-local C sources or `extern "C"` declarations.

## Official APIs

```zumbra
var app << desktopApp({"backend": "auto", "name": "Game"});
var window << desktopWindow(app, {"title": "Game", "width": 768, "height": 720});
desktopWindowPresentRGBA(window, pixels, 256, 240);
desktopWindowSetVSync(window, true);
var keyPressed << desktopKeyDown(app, 29);
var padPressed << desktopGamepadButton(app, 1, 0);
desktopAudioQueue(app, pcm, 80, false);
show(desktopAudioQueued(app));
show(processArgs());
show(unixTimeSeconds());
```

## Runtime behavior

- `desktopWindowPresentRGBA` accepts exactly `width * height * 4` bytes and presents an RGBA framebuffer through SDL3.
- `desktopAudioQueue` converts the unsigned emulator sample stream to signed 16-bit PCM, applies volume/mute and queues it through SDL3.
- `desktopKeyDown` reads SDL scancode state.
- `desktopGamepadButton` supports two dynamically refreshed gamepads.
- `desktopWindowSetVSync` controls the renderer VSync mode.
- The deterministic headless backend implements the same API for tests and CI.
- `processArgs` is available in the evaluator, VM and generated C11 programs.
- `unixTimeSeconds` returns a `u64` Unix timestamp in every backend.
- `createFile` and `writeBytes` now create missing parent directories and are supported by generated C11 applications.

The C/SDL implementation remains an internal runtime detail of Zumbra. Application repositories can now contain only `.zum` source code.

## Validation

```bash
scripts/test-0.14.3-desktop-media.sh
go test ./...
go vet -unsafeptr=false ./...
scripts/test-z18-tooling.sh
scripts/check-repository-hygiene.sh
```

A native application must still have SDL3 installed on the target system. Headless execution does not require SDL3.
